Emotion-aware 3D avatar

Shanaya’s React Three Fiber avatar uses model responses to animate supported expressions and idle movement, with a layout that adapts to desktop and mobile screens.

Multilingual voice chat

Use English, Hindi, or Marathi speech options where the browser or device provides compatible speech recognition and voice playback.

Cloud and optional local AI

Groq is the default cloud route. The project also supports configured providers, browser WebLLM, and native llama.cpp models on supported mobile devices.

Understand the data path

Choose how Shanaya processes your messages

In cloud mode, conversation content is sent through the configured Shanaya API to the selected AI provider to generate a reply. Provider privacy and retention terms apply. Optional local inference can keep prompts on the device after its model is available. Shanaya does not claim that cloud requests are offline or zero-retention.

Supported device actions use explicit confirmation prompts. Availability is limited by the operating system and app permissions; Shanaya does not have unrestricted control over every device or application.

Built for integration

A clear API for AI chat, agents, voice, and tools

Integrate Shanaya into a web app, mobile client, desktop shell, or automation workflow through a small Express API. Use the same-origin /api routes in production, keep provider credentials on the server, and select cloud or Ollama inference per request.

Chat and models

GET /api/health, GET /api/models, and POST /api/chat provide readiness, model discovery, and normalized replies with emotion metadata.

Agents and voice

POST /api/agent supports bounded tool-calling steps, while POST /api/tts proxies optional multilingual Mithi speech synthesis.

Secure extensions

Optional Pinecall token exchange, Electron computer use, and authenticated MCP tools keep sensitive credentials and provider calls behind the server boundary.

Read the API integration guide for cURL examples, schemas, environment variables, error codes, CORS, and production security requirements.

Common questions

About Shanaya

Does Shanaya work offline?

Optional offline inference is available with WebLLM in supported browsers and with a downloaded GGUF model in supported iOS and Android apps. First-time model downloads require an internet connection.

Which languages can I use for voice interaction?

The interface offers English, Hindi, and Marathi language choices. Speech recognition and speech synthesis depend on the voices and capabilities available in your browser or operating system.

Can Shanaya control my device?

Only the supported actions exposed by the current app are available. Sensitive actions require confirmation, and operating system permissions or restrictions still apply.

Is Shanaya a medical or emergency service?

No. Shanaya is software and is not a replacement for emergency services or professional medical, legal, or financial advice.
